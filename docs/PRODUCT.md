# DataReady v0.1 产品说明

## 1. 产品定义

DataReady 是一个面向商业分析场景的 Analysis Preflight 工具：它不替用户得出业务结论，而是在分析开始之前完成数据理解、质量检查、清洗建议、修改预览、执行、复检与可复现导出。

核心问题只有一个：

> **这份数据现在是否已经适合开始分析？**

## 2. 目标用户

v0.1 主要服务：

- 商业分析 / 经营分析；
- 策略运营；
- 数据分析；
- 产品 / 运营中需要快速处理 Excel 的用户；
- 收到别人发来的 CSV / Excel，需要尽快判断数据是否可靠的人。

第一版不把学术问卷 / SPSS 作为主场景。

## 3. 核心原则

### 3.1 Detection ≠ Modification

发现问题和修改数据是两个步骤：系统可以高置信度地指出「这里值得检查」，但不能因此自动决定「真实世界应该是什么」。

### 3.2 Human in the loop

所有修改必须进入 Cleaning Plan，重要修改必须经过 Preview 和用户确认。

### 3.3 Raw Data 永远不覆盖

原始 Dataset 是不可变基线。每次修改产生新的工作副本和 Action 记录。

### 3.4 确定性计算交给代码

缺失率、重复、类型、IQR、日期解析、基础逻辑规则等，不需要 LLM。

### 3.5 语义判断可以智能，但必须克制

类别合并、业务语境解释等适合 Semantic Provider。v0.1 先使用本地 alias / 规范化规则；未来可增加可选 AI Provider。

### 3.6 每一步都能解释、撤销、复现

用户应该始终知道：

- 为什么系统认为这是问题；
- 影响多少数据；
- 系统建议怎么做；
- 修改了哪些行 / 值；
- 如何撤销；
- 如何在 Python 中重新执行。

## 4. 核心流程

```text
Upload
  ↓
Understand
  ↓
Diagnose
  ↓
Review Issues
  ↓
Cleaning Plan
  ↓
Preview
  ↓
Apply
  ↓
Recheck
  ↓
Export / Recipe
```

## 5. 页面

### 首页

目标：10 秒内让用户理解 DataReady 是做什么的。

核心元素：

- 一句话定位；
- 上传区域；
- 体验示例经营数据；
- Local-first 说明；
- 简单流程。

### 数据概览

目标：回答“我上传了什么”。

展示：

- 行数 / 列数；
- 缺失单元格；
- 完全重复；
- 字段类型；
- 唯一值；
- 示例值；
- 基础统计信息。

### 数据问题

目标：回答“现在有哪些问题值得处理”。

问题按 Critical / Warning / Suggestion 分级，每张 Issue Card 包含字段、问题、示例、影响范围、解释、建议和风险等级。

### Cleaning Plan

目标：把分散的问题转成一份用户可审查的执行计划。

低风险操作可以默认选中；中高风险操作默认等待确认。

### 修改记录

目标：让用户能追踪和撤销操作。

每次 Action 记录操作类型、字段、影响范围和前后变化。

### 导出

目标：不仅输出结果，也输出处理过程。

- Clean Dataset
- Cleaning Log
- Cleaning Script
- Cleaning Recipe

## 6. Data Readiness

Data Readiness 是辅助指标，不代表绝对数据质量认证。

v0.1 使用五个维度：

- Completeness：20%
- Validity：25%
- Consistency：20%
- Uniqueness：15%
- Logic：20%

分数的意义主要是：

1. 快速提示当前数据是否存在明显风险；
2. 帮助用户比较清洗前 / 后状态；
3. 引导用户进入具体 Issues。

任何时候都不应该用一个分数替代具体问题解释。

## 7. 风险等级

### Low

可以默认加入计划：

- 完全重复行删除；
- 明确空值编码 → Missing；
- 高置信度数值文本转换；
- 无歧义日期格式标准化；
- 文本首尾空格清理。

### Medium

默认不自动执行：

- 类别语义合并；
- 缺失值填充；
- 删除常量字段。

### High

绝不默认执行：

- 删除异常值；
- Winsorize；
- 批量删除大量缺失记录；
- 修改可能含业务语义的数值。

## 8. Demo 设计

`Retail Operations Demo` 是虚构数据，不包含任何真实公司业务信息。

数据约 3,200 行，字段覆盖日期、城市、类目、商家、订单、GMV、折扣、配送成本、履约率、平均配送时长和状态等，并主动植入典型质量问题，用来完整演示 DataReady 的一条主链路。

## 9. v0.1 非目标

- 做 Excel 替代品；
- 做 BI；
- 自动写经营分析；
- 自动修正所有异常；
- 做 Agent；
- 做大型数据治理平台；
- 做完整 ETL / Join 工具。

范围越清楚，第一版越有价值。
